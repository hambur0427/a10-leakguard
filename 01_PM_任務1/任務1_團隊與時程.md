# 任務 1：團隊、角色與初始工作

## 專題目標

LeakGuard 掃描團隊 GitHub repo 中外洩的金鑰（API key、token 等），通知 repo 負責人，並讓負責人撤銷該金鑰並換新。目標是縮短「金鑰外洩到被撤銷」的時間，同時避免通知過多而被忽略。

## 要測試的兩個功能

1. **一鍵撤銷並產生輪替清單**（`one_click_revoke`）
2. **依嚴重度分級通知**（`severity_notify`）
